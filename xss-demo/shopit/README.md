# ShopIt

ShopIt is a simple, single-product shopping page built with React and Vite. It features a laptop product listing with pricing, specifications, and customer ratings, along with basic shopping cart functionality and customer reviews.

The project serves as a foundation for further development as part of a cybersecurity assignment.

## Development

Run `npm run dev:full` to start both the Vite frontend and Express API. The frontend is available at `http://localhost:5173`, and the API runs at `http://localhost:3000`.

To start only the backend, run `npm run server`. The SQLite database is created automatically at `data/shopit.db`.
